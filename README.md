# MAXX Sage

Bilingual artist website for MAXX Sage — singer, songwriter and podcaster.

## Highlights

- responsive design for desktop and mobile
- German and English content
- artistic editorial layout using the supplied MAXX Sage photography
- music-in-production section without premature streaming links
- Out of Tune podcast feature
- Instagram integration
- privacy-conscious setup without analytics or marketing cookies

## Development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

Build and validate with:

```bash
npm run build
```
