# MAXX Sage

Offizielle, zweisprachige Website von MAXX Sage.

## Lokale Entwicklung

```bash
npm ci
npm run dev
```

## Prüfung und Build

```bash
npm run check
```

Der statische Export wird in `out/` erzeugt. Änderungen am Branch `main` werden
über GitHub Actions automatisch zu GitHub Pages veröffentlicht.

## Domain

Die Produktionsdomain ist `www.maxxsage.com`. Die Domain wird in den
GitHub-Pages-Einstellungen des Repositories hinterlegt; die DNS-Einträge werden
bei GoDaddy verwaltet.
